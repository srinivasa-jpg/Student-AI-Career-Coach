# Student AI Career Coach

A student-focused career preparation dashboard for resume improvement, interview practice and skill readiness.

## Features
- Resume analyzer and career-ready checklist
- Target-role tracking
- Resume readiness score
- HR, behavioral, technical and career interview questions
- Answer tips and saved practice history
- Job-ready skill checklist
- Overall career readiness dashboard
- Responsive mobile UI
- Local browser persistence

> V1 uses local rule-based coaching and does not send resume data to an external AI service.

## Run locally
Open `index.html` in a browser or serve the repository with a static web server.
